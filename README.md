# china-site

The public pages for the China short-video accounts.

- `privacy.html` — the privacy policy of the `chinese-videos` Meta app. **This URL is configured in the Meta
  App Dashboard** (Settings → Basic → Privacy Policy URL, and User data deletion → Data deletion
  instructions URL) and is linked from the Facebook Login dialog. It must stay reachable at the same path.
- `index.html` — a holding page until the accounts' landing page is built.

The source of `privacy.html` is `docs/legal/privacy-policy.md` in the private `chinese-videos` repo.
Edit the two together.

Served by GitHub Pages from `main`, root.
